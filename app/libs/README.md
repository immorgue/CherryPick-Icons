# libxposed API 102 compile stubs

`libxposed-api-102.0.0.jar` is the unmodified `classes.jar` extracted from
https://repo.maven.apache.org/maven2/io/github/libxposed/api/102.0.0/api-102.0.0.aar
(official libxposed API, Apache-2.0). It is compileOnly and never packaged in the APK.
The framework supplies the API inside target processes. Do not invoke it in the settings app.

Source and license: https://github.com/libxposed/api
