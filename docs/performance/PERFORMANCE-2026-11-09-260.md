# 0.2.60-dev — подложка папки под неподнятой иконкой

`SurfaceMaterial` сохраняет описание подложки (маска, материал, геометрия) отдельно от View/RenderNode. `ParentBackdrop` строит составной GPU-шейдер обоев и ближайшей подложки. Иконки используют его в своей обычной GPU-отрисовке, включая Liquid Glass; никакой снимок иконок или повторный захват всего экрана не нужен.

Для закрытой FolderIcon и открытой OplusFolder фон может быть соседним View: запись связывается с областью папки, но её координаты берутся у настоящего View фона. Собственная подложка исключается по identity drawable. Материал GridRecyclerView находится обычным обходом родителей. FPS миниатюр/глобальный лимит сохранены, шейдер родителя переиспользуется детьми и меняется по его позе/настройкам.

Локально 54 unit-теста, assembleRelease и lintRelease успешны. Отдельный GPU-контракт tools/device-tests/run_parent_backdrop.py в изолированном app_process проверил пиксели Frosted/Liquid, вложенный Liquid-шейдер иконки, скруглённую маску, цветовой фильтр, следование переносу владельца, исключение самого себя и fixture-иерархии закрытой/открытой папки с соседним фоном. Fixtures и Xposed shims доступны только тестовому dex и в модуль не включаются.

0.2.60-dev установлена на телефон. В реальном launcher логом подтверждена привязка OplusBubbleTextView к GridRecyclerView. Это не является визуальной проверкой каждой модели папки на каждой прошивке. Программные CPU snapshots/старые API без RuntimeShader сохраняют прежние fallback-пути; новый родительский фон подключён к retained GPU-сэмплерам неподнятых иконок.
