# 0.2.54-dev — состояние изменений 8 ноября 2026

Основа: main 6dc2e73, включая PR #2 с редактором рабочего стола.
Это рабочая сборка для дальнейшей проверки пользователем.

## Изменения

- Исправлено прекращение live-блюра при быстром развороте открытия в закрытие:
  направление берётся из изменения нативной матрицы и может изменяться в полёте.
  Временная замена View.tag не завершает материал: сравнивается ID элемента и пользователь.
  В быстром сценарии возвраты, ранее имевшие 0 обновлений, получили 11–25 обновлений
  до штатного showOriginalIcon; лимит материала — не выше 30 FPS.
- Геометрия 1×2/2×1, независимые снимки значков и нативные BitmapDrawable сохранены.
  Потеря исходной bitmap-обёртки OEM не удаляет сохранённый слой значков.
- Для GridRecyclerView маска сохраняет нативное разрешение до 1024 px вместо
  уменьшения до 384 px и округления размера. Live-слой дополнительно ограничен
  точным силуэтом нативного снимка, чтобы стекло не выступало за его радиус.
  Обычная папка 2×2 не получает этот контур.
- Координаты preview учитывают матрицу родителя ровно один раз; исправлены
  повторное масштабирование и смещение вниз при записи вложенного RenderNode.
- В закрытой большой папке смена страницы обновляет нативную запись preview по
  изменению матрицы, до 30 FPS с финальным кадром после остановки.
- Статичный док сохраняет GPU-подложку при нативных scale/translation.
  Большой док рисуется в отдельном слое DragLayer, симметрично центру ряда,
  без ограничения исходной высотой hotseat и без прижатия к низу экрана.
- Маленькие иконки в папках: до 30 FPS, без отдельного преломления, с сохранением блюра/тона.
- Убраны лишние копии GPU-битмапов через CPU при удержании изображений.
  Восстанавливаются отброшенные нативным лаунчером вложенные display lists.
- Оптика Liquid из PR #2 — отдельный экспериментальный тумблер режима разработчика,
  по умолчанию выключен. Редактор рабочего стола сохранён независимо.
- Добавлены адаптеры редактора/размеров/тем для 16.x, 17.3.x и 17.5.4, а также
  фонового дока 16.x. Матрица и пределы проверки: [COMPATIBILITY.md](../../COMPATIBILITY.md).
- Кнопка репорта создаёт ZIP: diagnostics.txt с настройками и логами, device.txt,
  установленный APK OEM-лаунчера и splits, SHA256SUMS.txt. APK читаются потоком,
  без повторного сжатия; неполный архив не публикуется. Системный chooser получает
  application/zip и временный доступ через FileProvider.

## Обычное открытие: работа продолжается

Проверялся цикл «открыть → ждать 2,5 секунды → HOME → ждать 2,5 секунды».
В 0.2.53 подготовка свежего снимка мультипапки занимала 14–26 мс.
В 0.2.54 удалён неработавший на текущем телефоне промежуточный ImageReader backend;
слой значков остаётся GPU-битмапом, без обязательного CPU-readback.
Сэмплирование уже готового материала рабочего стола при открытии приостановлено.

Это ещё не полное исправление задержки первого открытия. В последнем холодном
замере создание сцен заняло 16,4 / 19,4 / 70,1 мс: остаточная блокировка пути
подготовки снимка требует отдельной работы. Объявлять открытие плавным по этим
данным нельзя. Дальнейшие визуальные проверки пользователь взял на себя.
