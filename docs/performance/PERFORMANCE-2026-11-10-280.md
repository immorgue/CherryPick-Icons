## Опережение

До изменений SwipePrediction возвращала весь горизонтальный сдвиг от предыдущего опубликованного sampler source, который обновлялся с частотой материала. При 30 FPS смещение накапливалось дольше; после прекращения workspace scroll опережение сразу исчезало. Это подтверждённое поведение кода, а не измерение зрения пользователя.

Новый режим `experimental_smooth_swipe_lead` включается только в режиме разработчика, default OFF. Старая ветка сохраняется. Новая ветка фильтрует velocity/lead с постоянной времени 35 мс, использует горизонт 16 мс и предел min(8 px, 10% ширины выборки). Native rawSource не сглаживается. Предсказание вычисляется в уже существующем pre-draw, material FPS не повышается. При остановке короткое затухание запрашивает кадры с выбранным FPS, без нового display-rate polling. Крупные прыжки, вертикальное движение, масштаб и handoff сбрасывают состояние. При 30 FPS сам материал остаётся 30 FPS; алгоритм не превращает его в 120 FPS.

Проверки: одинаковый горизонт при шагах 8/16/33 мс, плавное затухание к нулю, ограниченная смена направления, сброс на масштаб/вертикаль/скачок/NaN и reset после полёта. Новый эксперимент исключён из профилей обоев.

## Возврат иконки

prepareReturn ранее очищала историю движения, но оставляла frozenEffect/freezeGeneration и совпадающий finishKey. Если текущий source уже равнялся конечному source, samplerEffect могла вернуть true по contentMatches, не заменив установленный ранее blend effect. Это позволяло удержать устаревший статичный/смешанный материал после полёта.

Теперь handoff снимает frozen state, помечает текущую freeze generation завершённой для этого sampler и инвалидирует finishKey. На следующем pre-draw создаётся один актуальный эффект, даже если source совпадает. Не добавлен полный rebuild всех иконок или обход FPS в каждом кадре. Это локальное исправление инварианта; его связь с каждым наблюдаемым рывком не доказана.

## Вертикальное положение

Новые настройки desktop_grid_y / desktop_indicator_y / desktop_dock_y: −120..120 dp, default 0. Обмен через общий SettingsProvider и import/export схему; reset возвращает 0, профили обоев их не меняют.

DesktopOffsets снимает прошлую добавку до native layout и применяет новую после него через offsetTopAndBottom. TranslationY/scale анимаций не трогаются, layout database не записывается. Для вложенных целевых элементов вычитается желаемое смещение ближайшего целевого предка. Все три цели учитываются, даже при нулевом значении отдельной настройки. Удерживаются слабые ссылки. Нулевые настройки не меняют layout, landscape не смещается. Изменение настроек запрашивает layout.

Во всех шести локальных APK найдены три id и OplusDragLayer.onLayout. 14 групп контрактов прошли, ошибок нет. 41 отрицательный случай на пяти уникальных APK обнаружен. Локальный отчёт: E:/COSMOD/scratch/audit279/contracts280.json.
