## Адаптеры

- Снимок выбирается по полной статической сигнатуре, независимо от номера lambda.
- 16.x рисует исходную поверхность внутри IconSurfaceRecord; 17.x использует IconSurfaceRenderer.
  Токены записи и SurfaceControl ограничивают срок жизни отдельного live-слоя.
- Листание закрытой большой папки повторно записывает нативный preview при изменении
  матрицы страницы, с лимитом до 30 FPS и обязательным финальным кадром.
- Мультипапки используют штатный контур, радиус и размеры GridRecyclerView.
  У обычной папки 2×2 контур не изменён.
- Старый док оборачивает фон ShortcutAndWidgetContainer, сохраняя alpha, bounds,
  callback, padding и outline. Штатный фон скрывается только при отрисованном стекле.
  При выключении модуля/эффекта возвращается штатная отрисовка.
- DesktopNativeApi полностью разрешает контракт редактора перед установкой его хуков:
  порядок аргументов очистки, List/ArrayList, дополнительные аргументы 17.5,
  callback AsyncTask, поля страниц и индикатор занятости.
  Защита от удаления элементов в транзакциях редактора сохранена.
- Размеры рабочего стола читаются через поля DeviceProfile для всех трёх семейств.
  Вложенные вызовы расчёта размера иконок масштабируются один раз.
- В 17.5 LauncherIconConfig переименован в to5: добавлены адаптеры определения Flux,
  светлого/тёмного оформления и сброса кэшей при изменении темы.
  В 16.x нет isDarkIconEnable(Configuration): для оформления применяется существующий
  запасной выбор по системной теме, без вызова неподходящего isDarkModeIcon().
- Фабрики обоев: именованные callback/release или проверенная пара a/c (release=b).
  В 17.5 фабрика доступна через MaterialBlurAnimHelper; LauncherWallpaperManager отсутствует.

## Воспроизводимая статическая проверка

Из корня проекта, Python 3:

```powershell
python tools/launcher_contracts.py apks --output <local-cache>
python tools/verify_launcher_contracts.py <local-cache> --output <report.json>
```

Проверяются двенадцать семейств контрактов: полёт, передача возвращённой иконки,
paging, мультипапки, док, видимость пустого дока, родительские подложки папок,
снимки, редактор, геометрия рабочего стола, размер и оформление иконок.
Компактный результат с SHA-256: [`tools/launcher-contracts-2026-11-09.json`](tools/launcher-contracts-2026-11-09.json).
Полные DEX-кэши и APK в Git не включаются.

Аудит 9 ноября для 0.2.61: все 12 групп прошли во всех шести APK. Отдельно
проверены объявленные `OplusHotseat.onLayout`, `OplusFolder.onFinishInflate`,
`FolderRoundImageView.onDraw`, обе фоновые ImageView открытой папки, получение
границ иконок и сигнатура возврата IconSurfaceRecord. Обфусцированный предок
GridRecyclerView в 17.5 не используется адаптером подложек, который работает через View.
Несовместимостей новых функций не обнаружено; рабочий код модуля при аудите не менялся.
Дополнительно проверены манифесты: у всех APK пакет `com.android.launcher`,
разрешённый в HookEntry и queries модуля. Минимальный API — 33 у 16.x,
35 у 17.3.x и 36 у 17.5.x; API 33 для RuntimeShader доступен во всём этом наборе.

```powershell
python tools/test_launcher_contracts.py <local-cache>
```

Эта проверка удаляет обязательный метод или поле из копии DEX-модели: все
25 отрицательных случаев на пяти уникальных APK обнаружены. Для хуков,
устанавливаемых через `hookAllMethods`, проверяется объявление метода в целевом
классе: подходящего метода только у предка недостаточно.

## Испытания на устройстве

Для 0.2.61 прошли 56 unit-тестов, сборка release и lint. GPU-контракт
`tools/device-tests/run_parent_backdrop.py` проверил Frosted/Liquid, вложенный
шейдер иконки, цветовой фильтр, маску и перенос владельца, запрет выборки самого
себя и fixture-иерархии закрытой/открытой папки с соседней подложкой.
Изолированные fixtures и Xposed shims не включаются в модуль и не заменяют
проверку реального лаунчера на другой прошивке.

Текущий OnePlus PLZ110, Android 17 / API 37, установленный системный лаунчер 17.3.12.
На нём проверяются установка только модуля с сохранением настроек, обычные открытия
с ожиданием конца, быстрые чередования, возвраты, разблокировка, preview редактора
без применения сетки и ZIP-репорт. Проверка других прошивок остаётся статической.
Отдельный GPU-тест проверяет старую обёртку фона дока без установки старого лаунчера.

Для воспроизводимого баг-репорта кнопка в настройках модуля создаёт ZIP с логами,
настройками, данными устройства и APK установленного OEM-лаунчера, включая splits.
Архив содержит SHA256SUMS.txt. Передача выполняется через системное меню «Поделиться».
